# CubeIt

Simple TUI scambler for rubic's cubes

## Usage
```shell
cubeit # run with random scramble
cubeit -l "<STRING>" # run with provided scrumble string
```

## Installation
```shell
git clone https://github.com/enotinc/cubeit.git
cd cubeit/cmd/cubeit
go install # or you can use 'go build...'
```
